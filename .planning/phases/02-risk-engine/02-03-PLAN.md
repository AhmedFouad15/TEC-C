<feature>
  <name>Hard filters with reason codes</name>
  <files>agent/tecc_brain/risk/filters.py, agent/tests/test_filters.py</files>
  <behavior>
    FilterContext(tier: RiskTier, whitelist: set[str] | None (None = every venue whitelisted, offline demo),
                  heartbeat_alive: bool = True, max_slippage = 0.005, min_depth_multiple = 5.0)
    hard_filter_reasons(venue, quote, amount_usd, assessments, ctx, edge=None) → list[RejectReason] (empty = passes)
    RejectReason (str Enum): TIER_NOT_PERMITTED, NOT_WHITELISTED, FAILURE_VETO, NEGATIVE_EDGE, SLIPPAGE_TOO_HIGH,
                             INSUFFICIENT_DEPTH, HEARTBEAT_STALE
    Cases:
      - Balanced user, eigenlayer_restake (tier 3) → [TIER_NOT_PERMITTED]; Aggressive user → []
      - whitelist={"aave_v3_usdc"}, curve → [NOT_WHITELISTED] unless tier 3 (Aggressive bypasses whitelist, mirrors vault Tier 3)
      - usdc_distress snapshot with USDC p_failure forced ≥ 0.30 → aave_v3_usdc [FAILURE_VETO]; at SVB values (0.021) → no veto
      - sentiment ≥ 0.6 alone never produces a reason (asserted explicitly — this is the mentor point)
      - edge provided and ≤ 0 → [NEGATIVE_EDGE]; edge None → ignored
      - amount 25,000 into a venue with depth 100,000 → [INSUFFICIENT_DEPTH] (depth < 5×amount)
      - estimated entry slippage = entry_bps/1e4 + amount/depth > 0.005 → [SLIPPAGE_TOO_HIGH]
      - heartbeat_alive False → includes HEARTBEAT_STALE
      - multiple failures return all reasons in a stable order
  </behavior>
  <implementation>
    Pure function; no scoring here. Failure veto threshold 0.30 as named constant FAILURE_VETO_THRESHOLD.
    Export `passes(...) -> bool` helper. Document each reason's user-facing sentence in a dict REASON_TEXT for the UI.
  </implementation>
</feature>
