Beta with the asymmetric, value-weighted, capped, banded, decaying rules of BRAIN_DESIGN §3.2, and the profile
persists per account as JSON.

Purpose: "Adaptive with penalties and rewards" — the Brain earns autonomy slowly and loses it fast, and a user cannot
farm trust with dust trades. Every change is explained (a receipt the UI can show in "Your Brain").

  <behavior>
    models: LAMBDA_START {1: 3.0, 2: 1.0, 3: 0.3}; LAMBDA_BANDS {1: (2.0, 5.0), 2: (0.5, 2.0), 3: (0.0, 0.8)}.
    BrainProfile gains (all defaulted so profile_demo.json still loads): updated_at: datetime|None,
      tau_day: date|None, tau_gained_today: float, history: list[FeedbackRecord] (last 90 days),
      seen_events: list[str] (idempotency), preferences / cost_factors (filled by 05-02).
      new_profile(account, tier) → λ = tier start, τ 0.6, no approvals.

    learning.update:
      Signal (str Enum): RATIFY, FLAG, NOTE_PENALTY, NOTE, BREAKOUT_ACCEPT, BREAKOUT_REJECT, PICK_SAFER,
        PICK_RISKIER, IGNORED.
      FeedbackEvent(event_id, signal, venue_id|None, amount_usd ≥ 0, at: datetime, note: str = "").
      value_weight(usd) = clamp(1 + log10(usd/100), 0.5, 2.0); usd ≤ 0 → 0.5.
        $100 → 1.0, $10 → 0.5 (floor), $1,000 → 2.0, $10,000 → 2.0 (cap).
      learn(profile, event, now=None) → LearningResult(profile: new copy, changes: list[str], applied: bool).
        Input profile is never mutated.
        Order: decay → signal update → bands/clamps → record history + event_id.
        RATIFY α+=v, τ+=0.02v | FLAG β+=3, τ−0.15, λ×1.10 | NOTE_PENALTY β+=1.5, τ−0.07 |
        NOTE: nothing here (05-02 adds note sentiment ±0.5) | BREAKOUT_ACCEPT α+=1, τ+0.01 |
        BREAKOUT_REJECT β+=2, τ−0.05, λ×1.05 | PICK_SAFER chosen α+=0.5, λ×1.05 | PICK_RISKIER chosen α+=0.5, λ×0.95 |
        IGNORED: recorded only.
        Daily cap: τ gains on one UTC day sum ≤ 0.05; losses uncapped; τ ∈ [0, 1].
        λ always clamped to the tier band.
        Decay: every Beta moves toward the prior with a 30-day half-life of the gap since updated_at
          (x = prior + (x − prior)·0.5^(days/30)).
        Duplicate event_id → applied False, profile unchanged (sync can be re-run safely).
        Events with no venue (BREAKOUT_*) skip the Beta update but still move τ/λ.
      Cases: one FLAG costs as much τ as 7.5 RATIFY at v=1 (asymmetry); 20 RATIFY of $100 in one day → τ +0.05 only;
        dust ($1) ratify moves α by 0.5 not 1; λ for Balanced never exceeds 2.0 after 20 flags; Beta(5,2) after 30
        days with no events → (3.5, 2.0); replaying the same event twice changes nothing; changes[] human-readable.

    learning.store:
      ProfileStore(root: Path) with load(account) → BrainProfile|None, save(profile), get_or_create(account, tier).
      Account names validated (0x + 40 hex, or [A-Za-z0-9_-]{1,64}) — no path traversal.
      Atomic write (temp file + os.replace). Default root from env TECC_STATE_DIR else agent/.state/profiles.
      Round-trip preserves everything (datetimes, Beta tuples, history).
