<objective>
The Web3 Executor: an EIP-712 UserMandate committed on-chain as the session key's mandateRoot, the 117-byte session
signature verified by Ahmed's SessionKeyValidator as a pre-flight, then the vault-metered execution through the
ERC-7579 executor pathway, returning the Morning Review record id.
</objective>

<feature>
  <name>Mandate, session key, executor</name>
  <files>agent/tecc_brain/onchain/{mandate,session,executor}.py, agent/tests/test_onchain_executor.py,

  <behavior>
    mandate.UserMandate(account, sessionKey, maxAmountUsd (USD×1e8), validAfter, validUntil, policyHash) →
      EIP-712 digest (domain "Tec-C UserMandate" v1, chainId, verifyingContract = validator). Pure + unit-tested.
    session.provision(rpc, dep, session_key, mandate): owner opens the 5-minute biometric window, the account calls
      validator.registerSessionKey(…, mandateRoot = digest), hook.setSessionKeyAuthorization(true), and the account
      installs the session key as an ERC-7579 executor (no bundler). Idempotent per key.
    session.signature(key, hash, mandate_digest) → 117 bytes = sessionKey(20) ‖ sig(65) ‖ digest(32).
    executor.ChainExecutor(rpc, dep, key).submit(intent, account) → ExecutionIntent:
      execution calldata = target(20) ‖ value(32) ‖ data; USDC venues → USDC.transfer(venue, amount) (metered in USD
      by the hook via the USDC/USD feed); ETH venues → value to venue.stake(). Pre-flight: validator
      .isValidSignatureWithSender(account, keccak(calldata), sig117) == 0x1626ba7e, then eth_call; send signed tx
      from the session key; status "submitted" with tx_hash and recordId; any revert → status "failed" with the
      decoded custom error (TetherRadiusExceeded, UnauthorizedTarget, AIHeartbeatStale …) and nothing sent.
    Tests: $400 USDC into the Aave mock succeeds and leaves dailySpent = 400e8; $600 is refused by the vault
      (TetherRadiusExceeded) before sending; wrong mandate digest fails the pre-flight; a signature by another key
      fails.
  </behavior>
</feature>
