<feature>
  <name>Response playbook + reduce/opportunity cards</name>
  <files>agent/tecc_brain/strategy/playbook.py, agent/tests/test_playbook.py</files>
  <behavior>
    Response (str Enum): HOLD, HOLD_NO_NEW_DEPOSITS, EXIT.
    respond(asset: Asset, assessment: PegAssessment) → PlaybookEntry(response, destination: str|None, rationale)
      - dominant normal → HOLD
      - p_failure ≥ 0.30 → EXIT; destination by kind: stable_fiat/stable_crypto/stable_algorithmic → "shibor_mmf"
        (onshore rail outside the cluster), lst → "ETH" (native underlying, not a short), gold → "USDC"
      - otherwise (distress) → HOLD_NO_NEW_DEPOSITS; rationale mentions redemption/recovery
      - stable_algorithmic never gets HOLD unless dominant normal AND p_failure < 0.05; else EXIT

    reduce_exposure_cards(portfolio, view, risk, ref) → list[Card] (label REDUCE_EXPOSURE, mode BREAKOUT if amount
    exceeds nothing known here → use PROPOSE; planner may upgrade to BREAKOUT)
      - for every position exposed to a failing asset: card exiting the full position to the playbook destination
      - for every cap breach not already covered: card reducing the cluster by excess_usd, taken from the
        exposed position with the highest expected loss, destination shibor_mmf
      Cases: UST position 1,000 with UST failing → one card, amount 1000, destination shibor_mmf;
             cap breach 1,500 USDC + 500 ETH Balanced → one card amount 500
             distress-only USDC → no reduce card (do not sell temporary mispricing)

    opportunity_cards(view, snapshot, ref, budget_usd, costs=0.005) → list[Card] (label OPPORTUNITY, mode PROPOSE, action buy_discount)
      - for each assessed asset with discount_to_fv > 0 and dominant distress: edge = recovery_edge(...);
        card only if edge > 0; amount = budget_usd; explanation includes edge in %, P(recover), FV, price
      Cases: usdc_distress snapshot, budget 400 → one USDC card, edge in (0.02, 0.04); demo snapshot → none;
             UST early-style inputs → none (negative edge)

    Guard: no Response, card or action anywhere represents a short or delta-neutral hedge (assert ActionType values used ⊆ {deposit, stake, reduce_exposure, buy_discount, withdraw}).
  </behavior>
  <implementation>
    Pure functions; candidate inside cards uses Candidate(venue_id=destination or asset, action, asset_in, amount_usd, apy=0 for exits).
    Explanation lines are short, plain-English and carry the numbers.
  </implementation>
</feature>
