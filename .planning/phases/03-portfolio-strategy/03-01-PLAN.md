  <behavior>
    Models (add to models.py): Position(asset, venue_id: str|None, amount_usd ≥ 0); Portfolio(account, positions) with
    `nav_usd` property. Position exposures = venue.exposures if venue_id else [asset] if asset is pegged else [].

    assess_market(snapshot, ref) → MarketView(assessments: dict[symbol, PegAssessment], clusters: dict[id, ClusterStatus])
      - Pass 1: assess every peg in the snapshot with contagion 0.
      - Pass 2: k_i = max over links (j→i) of rho·p_failure_pass1(j); re-assess with contagion k_i (single step, no loops).
      - ClusterStatus(cluster, members, stressed = any member p_distress+p_failure > 0.5, failing = members with p_failure ≥ 0.30,
        worst_member, contagion_inputs dict).
      Cases:
      - demo snapshot → no stressed cluster, every k < 0.01
      - usdc_distress → usd_fiat stressed, failing [], DAI contagion = 0.8·p_failure(USDC) (± 1e-9)
      - demo with USDC forced to failure inputs (price 0.70, R 1, s 0.9, L 0.9) → USDC failing; DAI p_failure with
        contagion > DAI p_failure without contagion; usd_fiat failing contains USDC
      - assets present in snapshot pegs but missing from reference are ignored, not crashed on

    portfolio_risk(portfolio, view, ref, tier) → PortfolioRisk
      (nav_usd, cluster_exposure_usd, cluster_share, expected_loss_usd, expected_loss_fraction, cap_breaches)
      - expected loss per position: venue → venue_pd(venue)·venue.lgd; raw pegged asset → (1−(1−pd_base)(1−failure_excess))·asset.lgd; non-pegged raw (ETH) → asset.pd_base·asset.lgd
      - cluster caps apply to stablecoin clusters (usd_fiat, usd_algo) only: Conservative 0.60, Balanced 0.50, Aggressive 0.40 (CLUSTER_CAPS constant)
      - Balanced portfolio 1,500 USDC + 500 ETH → usd_fiat share 0.75 → one CapBreach(cluster usd_fiat, share 0.75, cap 0.50, excess_usd 500)
      - demo portfolio (1,500 USDC + 25,000 ETH) → no breach; expected_loss_usd equals hand sum to 1e-6
      - empty portfolio → nav 0, no division error, no breaches
  </behavior>
